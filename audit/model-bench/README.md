- 모델: `gpt-6-luna`
- 입력: 가상 1시간 회의 원문 67,451자 (실제 고객 회의 아님)
- 범위: 요약 + 14종 문서 생성 시도

```sh
FULL_OUT=audit/model-bench/full-luna-rerun LLM_PROVIDER=openai OPENAI_MODEL=gpt-6-luna npx vitest run --config audit/model-bench/vitest.bench.config.ts
```

신규 결과 폴더를 사용해 이전 실측을 보존하세요. 벤치마크는 실패·부분 생성 문서가 있으면 실패로 판정합니다.
